# 🌍 GlobeTrotter – Personalized Travel Planning (Java MVP)

## Problem Statement
Planning multi-city trips is complex due to scattered information, budget uncertainty, and lack of clear itinerary visualization. GlobeTrotter aims to simplify travel planning by allowing users to create personalized itineraries, add activities, and automatically calculate trip budgets.

## Solution Overview
This project implements the core backend logic of GlobeTrotter using a single Java program. It demonstrates how users can:
- Create a personalized trip
- Add multiple cities to the trip
- Add activities with costs for each city
- Automatically calculate the total trip budget
- View a structured itinerary output

Due to hackathon time constraints, this solution is implemented as a console-based MVP focusing on core functionality and scalability.

## Features Implemented
- Multi-city itinerary creation
- Activity planning per city
- Automatic budget calculation
- Clear console-based itinerary visualization
- Modular and extensible design

## Technology Used
- Java
- Object-Oriented Programming
- Console-based interaction
